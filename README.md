## apartment_gui is how you run the system 

The ProgressDocument explains what has been completed and what still needs to be done.

### Potential libraries that might need to be installed:
- pip install python-dateutil
- pip install tkcalendar

### To run login in page 
source .venv/bin/activate


### then either 
- python login.py to use the login page 
    
or

- python apartment_gui.py for quick testing
